## Project Overview

This repository contains an interactive map application (`index.html`) together with
supporting styles, JavaScript modules, and geospatial datasets.

The data is organized by thematic domains such as:

- **Boundaries**
- **Transportation**
- **Environment**
- **Amenities**
- **Social**
- **Disasters**
- **Urban Planning**
- **Energy**

## Repository Structure

- `index.html` – main map page.
- `style.css` – application styling.
- `JS/` – map behavior, UI, legend, export, search, and utility scripts.
- `data/` – geospatial datasets (`.geojson` / `.json`) grouped by topic.
- `info/` – dataset notes and metadata text files.
- `images/` – map/application image assets.


## Data Notes

- Dataset coverage focuses on Athens/Attica and selected nationwide layers.
- Files in `info/` provide context for the corresponding layers in `data/`.
